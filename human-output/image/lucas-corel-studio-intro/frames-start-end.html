Como usar

  1. Referência de rosto em toda geração. Anexe sempre as 2 fotos de retrato + referencia-rosto/frame-perfil.jpg. Sem elas a feição não trava.
  2. Ordem Start → End. Gere o Start primeiro. Depois de aprovar, gere o End usando o Start aprovado como imagem de referência adicional — é o que garante que o par pareça o mesmo instante, mesma luz, mesmo enquadramento.
  3. Config no Nano Banana: resolução 2K (não 4K — 4K fica plástico e perde grão), aspect ratio você define. Proporção sugerida 16:9 para todos.
  4. Blocos entre colchetes ([IDENTIDADE], [FIGURINO], etc.) já vêm expandidos dentro de cada prompt — é só copiar o bloco preto inteiro.
  5. Continuidade de ambiente: o estúdio é descrito por texto (não por imagem-ref) de propósito — evita "ref bleeding" e mantém os 14 frames no mesmo mundo.
